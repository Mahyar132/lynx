# Lynx

A simple, static link page.

## About

Lynx is a lightweight personal link page, similar to Linktree, built with HTML, CSS, and Bootstrap. It brings my website, social profiles, and other links together in one place.

## Features

- Simple, responsive layout
- Static HTML and CSS
- Custom fonts and styling
- No backend or database required
- No JavaScript frameworks
- Easy to host with GitHub Pages or Neocities

## Built With

- HTML5
- CSS3
- [Bootstrap](https://getbootstrap.com/)
- Custom CSS and fonts
